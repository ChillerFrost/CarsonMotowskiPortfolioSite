Projects & research

North Shore Health HIPAA Security Manual

North Shore Health, Internship project, 2026

Given this project at the start of my internship: build a HIPAA-aligned privacy and security manual for the organization. I began with a gap analysis of the existing compliance documents to see how much of the manual's content already existed, using Microsoft Copilot to quickly sift through hundreds of documents for anything related to IT and HIPAA security.

Once the gap analysis was done, I compiled the analysis, the compliance documents, and official templates from my supervisor into a single location in OneDrive. I then built a Copilot AI agent specialized in HIPAA policies and procedures, directing it with sources like HIPAA COW and the Code of Federal Regulations.

With those sources in place, I prompted the agent to draft the security manual: the compliance documents guided formatting and style, the templates provided structure, and the regulatory sources directed the agent in filling in content that addressed each requirement.
